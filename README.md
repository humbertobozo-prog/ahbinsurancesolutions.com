# AHB Insurance Solutions - Landing Page Professional

Esta es una Landing Page profesional y bilingüe (EN/ES) diseñada para una promotora de seguros especializada en Medicare, Gastos Finales e IUL.

## 🚀 Características
- **Bilingüe**: Cambio de idioma instantáneo.
- **Carrusel de Testimonios**: Interactivo y optimizado para móvil.
- **Formulario Multi-paso**: Alta conversión integrado con EmailJS.
- **SEO Optimizado**: Meta tags, Schema markup y carga de imágenes LCP.
- **Diseño Moderno**: Tailwind CSS con animaciones fluidas y Glassmorphism.

## 🛠️ Tecnologías
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Vite**

## 📦 Instalación Local
Si el botón de descarga falla, puedes crear una carpeta local y seguir estos pasos:
1. Crea un archivo `package.json` con el contenido del bloque de código.
2. Ejecuta `npm install`.
3. Copia el resto de los archivos (`index.html`, `App.tsx`, etc.).
4. Ejecuta `npm run dev`.

## 🔄 Cómo cambiar el repositorio de GitHub
Si necesitas mover este proyecto a un nuevo repositorio:
1. **Crea el nuevo repo** en GitHub (vacío).
2. **Cambia el remoto** en tu terminal:
   ```bash
   git remote set-url origin https://github.com/TU_USUARIO/NUEVO_REPOSITORIO.git
   ```
3. **Sube los cambios**:
   ```bash
   git add .
   git commit -m "Cambio de repositorio"
   git push -u origin main
   ```
